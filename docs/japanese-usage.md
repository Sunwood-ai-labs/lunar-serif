# LUNAR SERIF JP 日本語プレビュー

`japanese.html` は、LUNAR SERIF の日本語拡張版をローカルで試し打ちするための標本ページです。画面上では `LUNAR SERIF JP` と `Display版` を同じ文字列で並べ、かな・漢字・欧文・約物を組んだときの印象を確認できます。

## 起動

作業フォルダーでローカルサーバーを起動します。

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

ブラウザーで <http://127.0.0.1:8765/japanese.html> を開きます。`file:` で直接開くと、ブラウザーの制限によりカバレッジ JSON を取得できない場合があります。

## 標本の見方

- 上部の欧文標本で、LUNAR SERIF JP と Display版の N / O / S を比較できます。LUNAR SERIF JP では日本語のかな・漢字も同じ書体ファミリーで表示します。
- 「任意入力」に好きな文字列を入力すると、二つの書体の比較が更新されます。
- 16px / 24px / 48px のボタンで入力文字の大きさを切り替えられます。
- `ss01` を有効にすると、対応する O が装飾なしの字形に切り替わります。オフの状態では、標準の月と星の O を表示します。
- 標本には横書き、縦書き、ルビ、かな漢字、和欧混植、約物、合成済みと結合形の濁点・半濁点、半角カナを含めています。

## 各版の出典

- LUNAR SERIF JP は、独自設計の欧文 N / O / S などを維持し、和文の広い文字セットに Shippori Mincho の字形設計を統合した版です。基盤に欠けていた記号・半角カナ260文字を Noto Serif JP で補い、≒は独自の幾何輪郭を追加しています。
- Display版は従来の欧文と、生成見本から再構成した和文14字を保持します。二つの版で同じ14字を表示したときの差も比較できます。

## 読み込みと収録判定

ブラウザー表示用のファイルは次の場所に置きます。

```text
outputs/LUNARSERIFJP-Regular.woff2
outputs/LUNARSERIFJP-Regular.ttf
outputs/japanese-coverage.json
```

ページの読み込み表示は `document.fonts.load()` の戻り値を確認します。戻り値が空配列でない場合だけ読み込み成功とし、空配列や例外は失敗として扱います。LunarJP と LunarDisplay を個別に確認できます。

未収録判定は `outputs/japanese-coverage.json` の `characters` 文字列だけを参照します。JSON の取得・解析に失敗した場合は判定を保留し、取得失敗を収録済みとして扱いません。判定対象は任意入力に含まれる空白以外の文字です。

機械検証では、JP版・Display版それぞれについて `document.fonts.load()` の戻り値が空配列でないこと、coverage JSON が `characters` 文字列を持つこと、入力中の文字がその文字列に含まれるかを確認します。画面には結果だけを表示し、判定方法の詳細はこの文書に記録します。

## スクリーンショット

標本全体を残す場合は、ローカルサーバーを起動した状態でページを上から下まで撮影します。幅 1,280px 以上では横書きと縦書きのカードが並び、幅 700px 以下では縦に積み重なります。

## 配布

ブラウザーでは WOFF2 を優先し、対応アプリ向けに TTF も用意します。日本語文字の収録範囲は `japanese-coverage.json` と実際の表示を基準に確認してください。
