# 日本語版と生成画像の比較・実用検証

2026-09-13。LUNAR SERIF JP Regular 1.000は15,624文字・16,730字形。独自欧文104文字と装飾なしOを保持し、しっぽり明朝を主な和文基盤に、Noto Serif JPの補完260文字、独自の≒を加えました。元画像の和文14文字はDisplay 1.002に保持しています。

## 実施した確認と修正

- 生成画像に見本がある全50文字を、元画像／Display／JPの3列で比較。全9ページのWOFF2読み込み完了を確認して撮影しました。
- 補完261文字も3ページですべて目視確認。数学記号、ギリシャ文字、キリル文字、罫線、半角カナの欠け・空洞・配置を確認しました。
- 補完した5記号（＿｜｟｠￣）の縦書き代替字形を追加し、横組みとの実表示比較を保存しました。
- 試し打ちの16／24／48px、装飾なしO、半角カナ、濁点・半濁点、横書き、縦書き、ルビを確認しました。
- 見出しの「漢字」が途中で折り返される問題を文字サイズ調整で修正しました。縦書きの欧文が枠からはみ出す問題は、行の折返しと高さ指定で修正しました。
- 390×844のモバイル表示では、文書・入力カードの横方向のはみ出しがないことをDOMと画面で確認しました。入力した未収録の🦄は1文字として警告されました。

## 生成画像と残る差

| 対象 | 確認結果 |
|---|---|
| A–Z・数字 | JPとDisplayの独自輪郭・字送りは保持。画像との比較では高コントラスト、細線、セリフを確認。 |
| N・O・S | 大きいロゴの流れるN、月と星のO、細長いSを優先。一覧のOは装飾なしのため、一覧画像とは意図した差があります。 |
| C・E・S等 | 曲率・終端・線の太さには生成画像との差が残ります。元画像のロゴと小さい一覧自体にも揺れがあり、完全一致は主張していません。 |
| 和文14文字 | Displayは生成画像の筆致を再構成。JPは本文での統一を優先し、しっぽり明朝の字面・払いを採用。JPの方が同じemで和文の字面が大きくなります。 |
| 新規収録文字 | 生成画像に見本がありません。収録集合、実組版、本文サンプル、補完字の個別表示で確認しています。 |

字形比較ページではDisplay／JPのemとベースラインを統一しています。入力・本文ページでは通常のフォントメトリクスを使っています。元画像の小さい文字を拡大しているため、画像側のぼけや画素の段差をフォントの欠陥として数えてはいません。

## 機械検証

[checks.json](checks.json)に詳細を保存。JIS X 0208の6,879文字（第一水準漢字2,965、第二水準漢字3,390、非漢字524）をバイト列から列挙して照合しました。9例・計1,249文字の横組み／縦組み／混植コーパスも欠落ゼロです。

TTF／WOFF2のcmap、全輪郭、水平メトリクス、名前、OpenType機能を比較。独自欧文104文字と装飾なしOの輪郭・字送りを元版と照合しています。縦メトリクス、vert／vrt2、HarfBuzz組版、同梱OFLと著作権表示も確認対象です。

## 使用上の範囲

Regularのみ。JIS X 0213全体、全Unicode、IVS、絵文字、全人名異体字の対応は保証していません。全15,624文字の個別目視監査は未実施です。独自欧文の細線は16pxでは弱く見えるため、見出し・ロゴには24px以上を目安に実媒体で確認してください。今回の視覚検証はブラウザー上で行い、Word・DTPアプリ・印刷機の個別検証は未実施です。
